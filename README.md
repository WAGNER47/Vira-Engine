# Vira

Vira is a game platform and game engine made by Gatehouse Interactive, the studio Ramtin Mohammadi founded in Toronto.

Website: https://gatehouseinteractive.com

## Vira Engine

A no-code 3D game engine. You build levels, rooms, terrain, animation, sound and cutscenes in one window, then press Play. Logic Tiles let you write game behavior as short sentences instead of node graphs or code. Games are built to run on desktop, phones and VR headsets.

Vira Engine is in active development. Ramtin shares progress on Instagram at [@ramtinvibes](https://www.instagram.com/ramtinvibes/).
